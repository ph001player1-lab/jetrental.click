# Планы по порталу и ботам

Очередь задач, о которой договорились с владельцем. Сделанное — убирается отсюда.

## Ближайшие

1. **Статусы техники из портала** (обсуждаем) — аренда, свободна, бронь, ремонт берём из портала
   (отчёты рабочей группы и карточка), WS.Автопрокат только сверяем и показываем расхождения.
2. **Кабинет инвестора** — отдельная роль: свои машины, загрузка, доход.

## На будущее
